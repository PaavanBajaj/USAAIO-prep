# USAAIO Prep

Preparation for the USA AI Olympiad (USAAIO) and broader ML competition work.

## Topics Covered
- [ ] Linear algebra (vectors, matrices, eigendecomposition)
- [ ] Calculus for ML (partial derivatives, chain rule, backprop)
- [ ] Probability (Bayes, distributions, MLE)
- [ ] Neural networks from scratch
- [ ] CNNs
- [ ] Transformers / attention mechanism
- [ ] Reinforcement learning basics

## Structure
- `Foundations/` — math and stats prerequisites
- `Implementations/` — core ML concepts implemented from scratch in PyTorch
- `Papers/` — reading notes on key papers
- `competition-prep/` — USAAIO practice and past problems

## Stack
Python, PyTorch, Jupyter
