* <mark>unit/basis vectors</mark> : represented by *i hat* and *j hat* (in 2d specifically, in 3d and so on, there is one unit vector for each dimension). Litterally define the vectors of [1,0] and [0,1] respectively.

* representation of vectors using unit vectors: Any vector can be represented as a scaled i hat vector plus a scaled j hat vector

* <mark>Linear Combinations</mark> : The linear combination of vectors means scaling each individual vector by some scalar and adding the vectors together. 
    + Mathematical def: a* vector w + b* vector x = vector z. Here, a linear combination of vectors is used to define vector z.

* <mark>**SPAN** of two,more vectors</mark> : All possible linear combinations of two or more vectors are defined as the SPAN of two or more vectors
    + (Look at 3b1b Intro to Lin Alg Ep 2 Time point 5:35-6:45 to visualize)

* The only time the span of two vectors is not every possible vector is:
    1. If the vectors are <mark>linearly dependent</mark>, meaning one of the vectors is a linear combination of the other vector(s)
    2. If both vectors are the origin ([0,0])

* <mark>Basis of a vector space</mark> : The set of linearly independent vectors that can span that space
